# 小小说

在 VS Code 中按地址阅读小说，也可以输入书名，在已适配的网站中搜索。

## 使用方式

1. 打开 VS Code 左侧的“小小说”视图。
2. 在输入框输入书名或地址，插件会自动识别输入类型。
3. 点击“读取”打开搜索结果或小说正文。
4. 点击“返回”回到上一个搜索或阅读页面。
5. 点击“历史”可以查看搜索历史，并重新打开最近阅读过的页面。

搜索结果中，点击书名会优先打开章节目录；点击“开始阅读”可直接进入正文。阅读页顶部和底部都提供上一章、目录、下一章。

也可以通过命令面板运行 `小小说: 打开地址或搜索书名`。

## 网络环境说明

部分站点在特定网络环境下可能无法访问，需要配合可用的科学上网工具使用。

切换网络需重新加载 VS Code 窗口。

1. 按 `Ctrl+Shift+P` 打开命令面板。
2. 输入并选择 `Developer: Reload Window`。
3. 等待 VS Code 窗口重新加载完成。
